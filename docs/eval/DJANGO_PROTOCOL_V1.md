# Django 中文语义搜索试点协议 v1

本轮评估自然语言单次搜索的代码证据覆盖。中文为主成绩，英文为同题等价对照；10 道独立开发题共 20 次查询，不算 20 道独立任务。当前只有 ACE 组，后续开源工具与 OpenContextEngine 使用相同范围、问题和预算。

## 固定输入

| 项目 | 本轮设置 |
| --- | --- |
| 仓库 | `django/django` |
| 代码版本 | `f59aef2ee9b5c988fd4179d8f2835030bd76297c`，从 `stable/5.2.x` 固定 |
| 索引范围 | 该版本下全部 883 个 `django/**/*.py`，共 5680101 字节 |
| 排除范围 | 测试、文档、模板、翻译、静态资源及 OpenContextEngine 评测资料；不按题目相关性筛生产 Python 文件 |
| 题目 | 登录、路由、中间件、事务、CSRF、页面缓存、配置、上传、信号、类视图权限 |
| 参考答案 | Codex 在本轮 ACE 查询之前逐题阅读固定源码，标注 40 个必需事实及其代码证据 |
| ACE 接口 | `@augmentcode/auggie-sdk` 0.2.0，`DirectContext.search()`，请求最大返回 40000 字符（实际响应长度见结果） |
| 查询顺序 | 逐题执行，中英先后交替；每个语言版本只运行一次，无 Agent 追问或回答模型 |
| 主预算 | 4000 token；补充预算 2000、8000 token |
| Tokenizer | `js-tiktoken` 1.0.21 的 `cl100k_base`，不将字符数当 token 数 |

英文不增加中文没有的符号、路径或解题线索；中英文共享同一份答案。题目是日常语义定位，包含简单单文件和必要的跨文件联系，不要求所有问题刻意避开代码中的常见业务词。协议、问题、答案、文件清单及实现哈希在首个请求前记录于 [freeze.json](../../eval/django-v1/freeze.json)。

## 参考答案与评分

可阅读的事实及源码链接见 [参考答案 v1](DJANGO_REFERENCE_V1.md)，精确范围、原文和哈希见 [answers.v1.json](../../eval/django-v1/answers.v1.json)。每题拆成若干必需事实，每个事实可有多个等价证据方案；一个方案内可能需要多个片段共同支持。v1 使用本轮已核验的实现片段，后续发现等价方案按版本修订，不暗中改变评分口径。

每份响应保留原始顺序和原文，路径、行号等元数据也计入预算。从响应开头截取 B token，再去除末尾不完整行，不依据答案挑选或重排片段。即使关键代码在预算外，也不补进预算内结果；同时保留不受本地 token 截断的原始响应诊断分，区分返回遗漏与预算截断。

返回的每条带行号代码先与固定源码逐行比较。未知路径、错误行号、被改写或截断的代码行不计为有效证据。某个事实的任一等价方案所需代码行全部出现时，该事实命中；各事实等权。路径正确、只出现符号名或零散关键词不能代替代码证据。

`Coverage@B = 命中的必需事实数 / 该题必需事实总数`

先计算每题覆盖率，再对 10 题等权取平均，中文与英文分别统计。遗漏率为 `1 - Coverage@B`；完整召回率是全部事实命中的题目比例。每题列出遗漏事实，不能只报总分。英文均值减中文均值以百分点报告，作为这一批配对查询的描述，不声称统计显著或所有任务都有相同语言差异。

自动分数严格衡量本版本预标注源码证据的覆盖，不声称证明全部潜在答案已找齐。后续源码复核发现等价证据或标注错误时，应发布新答案版本、保留旧分，并对所有组已保存的原始响应统一重算；只修订答案通常不需要重跑 ACE。

未标注的返回代码不自动算无关，因此本轮不把“参考片段之外的所有 token”冒充噪声率。无关内容比例需另做相关性复核。报告实际查询耗时、返回 token 和失败；SDK 未给出账单金额时保持未知。

## 失败与运行约束

整轮最多 600 秒；索引阶段最多 240 秒，每次逻辑查询最多 60 秒，单个 HTTP 请求最多 45 秒。最多 160 个 HTTP 请求，其中检索请求最多 24 次，允许 SDK 的少量可重试服务端失败但不无限重试。任何逻辑查询失败均记录并停止后续查询；失败与未运行项按零覆盖进入计划任务分母，同时单独报告其数量，不能删掉后只统计成功题。

代码只向官方租户的索引和检索端点发请求，不调用 `searchAndAsk()` 或聊天端点，不上传标签。凭据由用户既有本机会话提供，运行记录不包含 token 或租户地址。每条响应结束即保存，整轮超时仍保留已完成结果。

## 复现与离线分析

先取得对应 Django commit，然后执行：

```sh
npm ci
npm run prepare-django -- /absolute/path/to/django
npm test
npm run ace-django -- --dry-run
```

`--dry-run` 检查文件和标签哈希、源码范围、依赖及运行上限，不发起网络请求。完成本机 `auggie login` 后，以下命令会实际使用 ACE：

```sh
npm run ace-django
```

日志会输出本地运行目录。已有结果的评分无需再次访问 ACE：

```sh
npm run score-django -- runs/ace-django-TIMESTAMP
```

运行目录保存固定输入、索引状态、请求状态与耗时、20 份原始响应；评分后增加各预算的响应前缀与逐事实分数。`runs/` 不进入 Git，长期留存需单独备份；本轮资料未自动上传或发布。Django 参考源码片段保留其 [许可证](../../eval/django-v1/DJANGO_LICENSE.txt)。

这是开发试点，无保留集、无重复运行、无独立多人标注；不能用于宣布全面优于某个工具。Agent 多轮效果不在本轮范围内。
